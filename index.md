# Clarity

Clarity is a dark, minimal Android app for tasks, a calendar and a private password vault, with home-screen widgets for each.

## Features

- To-do list with reminders and a home-screen widget
- Calendar widget
- Encrypted password vault with a master password and optional biometric unlock, plus a Vault widget
- Custom widget wallpapers and fonts
- Optional backup and restore to your own Google Drive

## Privacy

Clarity has no servers and no ads, and it does not track you. Read the [Privacy Policy](privacy.md).
